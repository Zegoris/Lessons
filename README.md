## Запуск

Зависимости и порядок запуска у каждого проекта свои. Общий порядок:

```bash
git clone https://github.com/Zegoris/Lessons.git
cd "Lessons/<папка_проекта>"
pip install -r requirements.txt
python [главный_файл].py
```

Для ботов и навыка Алисы нужны токены. Их задают в [переменной окружения / конфиге] и не добавляют в репозиторий.
